# unity_vr_rzuty

Projekt generowany maszynowo za pomocą Claude Code i modelu Opus 5.5.

Rzucanie w VR na Meta Quest 3S w Unity 6.3 LTS (6000.3.24f1): **kosz** (wymiary FIBA, trafienia, wyzwanie 60 s) i **kręgle** (tor 18,29 m, 10 kręgli z fizyką, pełna punktacja 10 ramek). Porównanie trzech metod liczenia prędkości rzutu (OVRInput / historia / ostatnia klatka), pomoc w celowaniu, podgląd toru lotu, grawitacja Ziemi, Marsa i Księżyca. Sterowanie tylko kontrolerami Touch (`OVRInput`), grafika z prymitywów Unity, dźwięki syntetyzowane w kodzie.

Szybki start: otwórz projekt, a potem **VR Rzuty › 0. Szybki start**. Uruchamianie: **VR Rzuty › 3. Build And Run (USB)** albo **4. Patch And Run**.

Instrukcja konfiguracji, Build & Run przez USB, optymalizacji, obsługi w goglach i opis działania: [INSTRUKCJA.md](INSTRUKCJA.md)
